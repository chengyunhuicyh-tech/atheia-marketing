# Monthly Input Brief — question set

`.agents/product-marketing.md` covers everything durable. This file is just the handful of things that change month to month — ask about these, infer everything else.

| Field | How to fill it |
|---|---|
| Month + year | From the user's request ("plan July" → July 2026) |
| Key calendar anchors | Check the SG calendar below for this month; ask if anything brand-specific (drops, anniversaries) applies |
| Pop-ups confirmed? | Ask — dates, venue, audience, in-person discount. If none, note "no pop-ups this month" |
| Running a sale? | Ask — if yes: dates, length, mechanic (item-based / cart-value), tiers, free-shipping lever |
| Product focus / drops | Ask — new colourway, hero product, or evergreen rotation? |
| Budget for the month | Default to the context file's confirmed envelope (§6) unless told otherwise |
| UGC creator | Ask — booked / KIV / deferred (default: KIV per context file unless changed) |
| Affiliate | Ask — active / KIV / deferred (default: KIV per context file unless changed) |
| Starting numbers | Pull from last month's "Numbers vs target" table — orders, IG followers, email subs, open rate |
| Carry-ins from last post-mortem | From Step 1 of SKILL.md — double down / drop / test |
| Team capacity flags | Ask only if relevant — travel, low-bandwidth weeks |

## Question-asking rule

Batch the genuine unknowns into one short round — typically 3–5 questions covering sale, pop-ups, product focus, and any capacity flags. Budget, channel doctrine, and starting numbers should already be answerable from the context file and last month's data without asking. If you find yourself asking more than 5 questions, something that should be a default is being re-litigated — check the context file first.

## SG calendar reference

Durable anchors — check which fall in the target month:

- **6.6 / 7.7 / 8.8 / 9.9 / 10.10 / 11.11 (Singles' Day) / 12.12** — platform sale dates, strong e-commerce intent.
- **Great Singapore Sale (GSS)** — roughly Jun–Aug; "mid-year sale" framing fits here.
- **National Day (9 Aug)** — local-brand / "made in SG" angle.
- **Black Friday / Cyber Monday** — late Nov; biggest discount moment of the year.
- **Christmas / year-end** — gifting + "new year, new routine" runway into Jan.
- **Chinese New Year (Jan/Feb)** — gifting + fresh-start fitness intent; note logistics slowdowns.
- **Climate note:** SG is hot/humid year-round — the BreezeCool "built for the heat" message works every month, but spikes around mid-year or any heatwave news.
