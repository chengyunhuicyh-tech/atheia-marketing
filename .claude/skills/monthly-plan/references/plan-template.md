# Plan Template & Generation Rules
Mirror this structure so the output pastes cleanly into the Notion Month Overview. H2 headers throughout for clean paste.

## Theme (1–2 sentences)
The month in one breath: the 1–2 big moves (pop-up? sale? content push?) plus the channel doing the heavy lifting. Note any change from default doctrine and why.

## Targets table
Ground every number in last month's actuals plus this month's moves — never in aspiration alone. Standard rows:

| Metric | Start | Target end of month |
|---|---|---|
| Total orders (cumulative) | | |
| Email subscribers | | |
| Instagram followers | | |
| Pop-ups completed | | |
| Sale orders (if sale) | | |
| Sale AOV (if sale) | | |
| Sale ROAS (Meta) | | |
| Meta CPC | | < SGD $1.50 |
| Welcome-series open rate | | ≥40% |
| Abandoned-cart recovery | | ≥5% |
| UGC Reels received | | (0 if KIV) |
| Affiliate redemptions | | (0 if KIV) |

If a metric is unknown, say so explicitly rather than inventing a number.

## Budget
Confirmed total + line items (Meta split, pop-up materials, free-ship margin, conditional Reel boost, conditional UGC). State the floor and the ceiling separately — never collapse them into one number.

## The 5 priorities if the month gets tight
Always anchored to the spine: (1) email flows live, (2) execute pop-ups well, (3) run the sale cleanly, (4) close the content gap (UGC), (5) daily Stories in sale/pop-up windows. Re-order to fit the month; cut whatever doesn't apply this month. End with "everything else amplifies these 5."

## Channel plan

- **Instagram:** carousel count + pillars · Stories density curve (high/medium/low by week) · Reels (source) · feed posts (reserved for genuine moments only).
- **Email:** flows (live/maintain) + broadcasts (which 2, dates, plain-text founder voice).
- **Meta:** retargeting (creative swap, no campaign restart) + sale push (budget/day, ATC → Purchase switch) + buffer. Destination always the PDP. No cold-as-sales.
- **Pop-ups:** dates, 3-job framework, contact-capture reminder, verbal handoff script for this month's mechanic.

## Sale structure (only if running one)
Dates · mechanic · tier table · free-shipping lever · two-peak shape if the sale runs longer than 5 days · launch-day sequencing · close/cleanup reminder (e.g. restore the $50 free-shipping threshold).

## Week-by-week todo skeleton
One block per week with a theme line and checkbox tasks. Map tasks to the calendar anchors identified in the input brief.

## Founder stagger plan (launch/sale-launch day only)
Two columns — Founder A (Launch Ops) / Founder B (Customer & Content) — time-boxed across the day.

## End-of-month reflection scaffold
What worked · what didn't · numbers vs target · carry into next month (double down / drop / test). Leave blank — this gets filled at month-end, not now.

---

## Generation rules — the quality bar

1. **Ground every number in real data.** Targets reference last month's actuals, not aspiration. If a metric is unknown, say so — don't invent.
2. **Respect the permanent cut-list.** Don't reintroduce WhatsApp, Klaviyo, heavy email, gifting-for-posts, or cold-as-sales. If proposing to switch on a KIV item, say explicitly what changed to justify it.
3. **Sale comms are tier-led, never discount-led.** "Buy more, save more" — not "everything on sale."
4. **Ads → PDP.** Every sales ad destination is the product page. Cold is judged on CPC + followers only.
5. **Executable by 2 people who can't film themselves.** Canva + phone + CapCut by default; paid UGC for live video. If a tactic needs more than that, it's KIV.
6. **Don't pretend budget exists.** Confirmed vs. conditional must be explicit. Meta is a retargeting net, not a discovery engine.
7. **Reference, don't duplicate.** For visual specs, point to Brand System; for positioning, point to the context file. This is what avoids the drift problem.
8. **Notion-paste-ready.** H2 section headers, tables for anything structured, checkboxes for todos.
9. **Carry the learnings.** Every plan should visibly reflect the hard-won learnings (§8 of the context file) and last month's post-mortem carry-ins.
