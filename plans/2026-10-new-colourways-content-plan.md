---

## 1. Ground rules for every piece of content

| Rule | Detail |
|---|---|
| **October = Stories only for the new colours** | No feed posts or ads that show the new colours until the model photos are ready (1 Nov) |
| **October feed = 3 evergreen carousels (optional)** | Text-led Canva posts using **existing** photos, so the grid doesn't sit silent for a month. None of them show the new colours. Drop them if you'd rather keep the feed fully quiet |
| **Every product Story links to the PDP** | Link to the **colour variant** URL (`?variant=…`) so the right colour is already selected. Never link to the profile or homepage |
| **UTMs on every link** | `utm_source=instagram&utm_medium=story&utm_campaign=newcolours_oct26&utm_content=glacier` (swap the colour) so you know which colour is getting the taps |
| **Honest scarcity only** | *"We made 50 of each"* is always true. *"X left"* only when it's real |
| **No member filming** | BFT content = stand, rack, products, notes. No people |
| **Founders never on camera** | Hands-only video (unboxing, packing, fabric stretch) is fine |
| **Voice** | Founder register: "for the SG heat", "from studio to kopi". Light Singlish in **Stories only**. No "babe / obsessed / y'all" |
| **Emojis** | Max 2 per caption, never in carousel headlines. Use 🌿 ☀️ 🤍 📍 🛍️ |
| **Currency** | Always `S$` |
| **Visuals** | Bone Cream base, Deep Charcoal text, Reckless Neue + Inter, one accent per carousel, warm filter (Warmth +15, Sat −10, Bright +5) on every photo |
| **Hashtags** | Rotate sets A (general) / B (fabric) / C (community). Never the same set twice in a row. D (sale) isn't used, since there's no sale |
| **Default posting times** | Weekdays 8pm, weekends 10am. Check IG Insights → *Most active times* and adjust after week 1 |

### Content pillars for these 2 months

| Pillar | Hook it serves | Share | Examples |
|---|---|---|---|
| **The drop** | *Feel the difference* | 40% | Colour reveals, outfits, stock updates |
| **Fabric & fit education** | *Feel the difference* | 20% | Why BreezeCool, which support for which class, the squat test |
| **Studio to kopi (lifestyle)** | *From studio to kopi* | 15% | 7am class → kopi, ways to wear the tank |
| **Honest brand** | *No brand markup* | 10% | What "no brand markup" means, hand-written notes, founder notes |
| **Community & proof** | Social proof | 15% | Customer reposts, BFT, reviews |
